# hub

別のホストで動いている自分の Claude Code セッションへ、メッセージを送れるようにするプラグインです。

Claude Code 標準の SendMessage は同じマシンのセッションにしか届きません。hub は中継サーバを 1 つ挟むことで、ホストをまたいで同じことをできるようにします。各セッションは中継サーバへ外向きに HTTP でつなぐだけなので、ホスト同士が直接つながっている必要はありません。

## インストール

Claude Code のプロンプトで:

```
/plugin install hub --marketplace shuntacurosu/shuntacurosu-plugins
```

メッセージをやりとりしたいすべてのホストで入れてください。

## 用意するもの

1. **中継サーバ**: すべてのホストから HTTP で届く場所に 1 つ。このプラグインの `server/` に見本が入っています。
2. **各セッションの環境変数**: 中継サーバの場所と、自分を示すトークン。

## 中継サーバを動かす

Node.js 20 以上があれば、追加のインストールなしで動きます。

```bash
cd server
RC_TOKENS="好きな文字列:alice" PORT=8080 node index.js
```

`RC_TOKENS` は `トークン:ユーザー名` をカンマ区切りで並べたものです。同じユーザー名のセッション同士だけがつながり、別のユーザーのセッションは一覧にも出ません。

```bash
RC_TOKENS="tokenA:alice,tokenB:bob" node index.js
```

これは見本です。そのまま外に出す場合は次の点に注意してください。

- 通信は平文の HTTP です。トークンが流れるので、TLS を終端するプロキシの後ろに置いてください。
- 名簿と未読メッセージはメモリ上にしかありません。サーバを再起動すると未読は消えます (各セッションは自動でつなぎ直します)。

## セッションを起動する

```bash
export RC_HUB_URL=http://中継サーバ:8080
export RC_HUB_TOKEN=tokenA
claude
```

| 環境変数 | 意味 |
|---|---|
| `RC_HUB_URL` | 中継サーバの URL (必須) |
| `RC_HUB_TOKEN` | 中継サーバに登録したトークン (必須) |
| `RC_AGENT_NAME` | このセッションの名前。省略すると作業フォルダの名前 |
| `RC_HOST_NAME` | ホストの名前。省略すると `hostname` の結果 |
| `RC_AUTO_ON` | `1` にすると、起動時に自動で `rc on` |

セッションは `名前@ホスト` (例: `alpha@host-a`) で呼ばれます。同じ名前のセッションがすでに居るときは `alpha-2@host-a` のように番号が付きます。

## 使い方

| 操作 | 内容 |
|---|---|
| `/hub:rc on` | このセッションを、他のセッションからメッセージを受け取れる状態にする |
| `/hub:rc off` | やめる |
| `/hub:rc` | 今の状態を表示 |
| `/hub:list-agents` | つながっている自分のセッションの一覧 |
| `@@` | 送り先の候補が出る。Tab で確定 |
| `@@alpha@host-a 本文` | 送信 |

- 送る側も受ける側も `/hub:rc on` が必要です。
- 送り先は、他と紛れなければ `@@alpha` のように短く書けます。
- `@@` は、そのセッションの Claude が作業中でもすぐ送られます。
- `/hub:rc` と `/hub:list-agents` は、Claude が作業中に打つと作業が終わってから実行されます。

### 届いたとき

| 受け取る側の状態 | どうなるか |
|---|---|
| Claude が作業中 | 画面に `✉ Message from @@送り主: ...` と出て、今のツールが終わり次第、同じ作業の中で読まれる |
| 待機中 | そのメッセージで新しいやりとりが始まる |

実行中のコマンドを途中で止めることはありません。これは標準の SendMessage と同じ動きです。

受け取った Claude は、必要なら自分で送り主へ返信します。返信は送り主のセッションに同じ形で届きます。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| `RC_HUB_URL and RC_HUB_TOKEN are not set` | 環境変数を設定してから `claude` を起動し直す |
| `unknown or missing hub token` | トークンが中継サーバの `RC_TOKENS` に入っているか |
| 一覧に相手が出ない | 相手も `/hub:rc on` しているか。相手と同じユーザーのトークンか |
| 入力欄の下に `hub unreachable, retrying` | 中継サーバに届いていない。復旧すれば自動でつなぎ直す |
| `@@` を打っても送られず文面が残る | 理由がその上の行に出ている (rc が off、宛先が居ない、など) |

## 知っておくこと

- 届いたメッセージは、受け取った Claude がそのセッションの権限で実行します。中継サーバにつなげるのは、信頼できる自分のセッションだけにしてください。
- Claude Code 2.1.322 で動作を確認しています。プラグインが使っている仕組みは early access で、今後の更新で変わる可能性があります。
